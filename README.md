# Python Calculator

A simple command-line calculator written in Python.

## Features
- Enter as many numbers as you want
- Choose an operation: addition, subtraction, division or multiplication
- Handles division by zero without crashing

## How to run
1. Install Python 3
2. Download `Calculator.py`
3. Run: `Calculator.py`

## How it works
1. The program asks how many numbers you want to enter.
2. Enter each number when prompted.
3. Choose an operation:
   - 1 = Addition
   - 2 = Subtraction
   - 3 = Division
   - 4 = Multiplication
4. The result is printed.
